# Home Automation System

## Description
This project is a home automation system with features for user registration, login, and profile management. The system uses React for the front-end, MySQL for the back-end, and Java with Servlets and JSP for server-side operations.

## Technologies Used
- React
- Java (Servlets, JSP)
- MySQL
- Maven
- Mockito (for unit tests)

## Setup Instructions
### Frontend (React)
1. Install Node.js and npm (if not installed).
2. Clone the repository.
3. Run `npm install` to install the required packages.
4. Run `npm start` to start the React development server.

### Backend (Java Servlets and MySQL)
1. Make sure you have MySQL installed and running.
2. Set up a database with the required tables for users.
3. Import the project into your IDE (e.g., IntelliJ).
4. Run the project on a Tomcat server.

## Usage Instructions
1. Open the app and register a new user.
2. Once registered, log in with the credentials to view your profile.

## Testing
Run unit tests in `src/test` using a test runner like JUnit.
